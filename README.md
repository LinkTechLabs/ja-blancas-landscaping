# J&A Blancas Landscaping Website

## Live Preview Options:

### Option 1: Direct File Access
You can view the website directly through these raw file links:
- **HTML**: https://raw.githubusercontent.com/LinkTechLabs/ja-blancas-landscaping/gh-pages/index.html
- **CSS**: https://raw.githubusercontent.com/LinkTechLabs/ja-blancas-landscaping/gh-pages/style.css
- **JS**: https://raw.githubusercontent.com/LinkTechLabs/ja-blancas-landscaping/gh-pages/script.js

### Option 2: GitHub Pages (Manual Setup)
1. Go to: https://github.com/LinkTechLabs/ja-blancas-landscaping/settings/pages
2. Under "Build and deployment", select "Deploy from a branch"
3. Choose "gh-pages" as the source branch
4. Click "Save"
5. Your site will be available at: https://linktechlabs.github.io/ja-blancas-landscaping/

### Option 3: Local Preview
1. Download the files from the repository
2. Open `index.html` in your browser
